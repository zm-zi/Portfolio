## 按角色推荐阅读路径

| 角色 | 推荐阅读顺序 |
|---|---|
| 新人入职 | README → GLOSSARY → 世界观设定 |
| 关卡策划 | PVE模式设计 → 战场与操作 → 兵种框架设计 |
| 系统策划 | 战场与操作 → 局外系统（全部5篇）→ 游戏模式 |
| 数值策划 | 兵种框架设计 → 具体兵种数据 → 将军系统设计 |
| 客户端程序 | 战场与操作 → 全局UI模块 → 局外系统 → 模块文档（PVE面板/部队面板） |
| 美术/UI | 世界观设定 → 具体兵种数据 → 全局UI模块 → UI/ 示意图 |
| 文案/叙事 | 世界观设定 → 叙事脚本 → PVE模式设计 |
