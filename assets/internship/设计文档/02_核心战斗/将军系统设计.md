# 将军系统设计

| 版本 | v1.0.0 |
|---|---|
| 日期 | 2026-07-20 |

---

## 一、系统概述

将军是局内战斗的核心决策维度之一，与 8 个携带兵种共同构成出战卡组。每局携带 1 名将军，提供被动 Buff、主动技能和部署策略三重影响。

| 项目 | 说明 |
|---|---|
| 携带数量 | 每局 1 名将军（卡组 8 兵种 + 1 将军） |
| 被动 Buff | 全场生效，为携带兵种或全军提供属性加成 |
| 主动技能 | 与兵种共同进入军令满条时的四选一弹窗，消耗军令释放 |
| 部署策略 | 直接决定大本营（军营）的血量、护盾和攻击 |
| 同时佩带 | 仅可佩带 1 名将军 |

---

## 二、品质

| 品质 | 标识 | 说明 |
|---|---|---|
| 常规 | 白 | 基础将军，被动 Buff 和主动技能数值较低 |
| 精锐 | 蓝 | 进阶将军，Buff 数值和技能效果提升 |
| 特种 | 紫 | 高级将军，拥有独特技能机制 |
| 战略 | 金 | 顶级将军，技能效果显著，改变战术格局 |

品质直接影响被动 Buff 数值、主动技能强度和部署策略加成幅度。

---

## 三、学派体系

将军从属于联防军内部五大战术学派，非阵营选择，代表同一体系内的不同战术理念：

| 学派 | 理念 | 气质 | 战术倾向 |
|---|---|---|---|
| 装甲学院 | 重甲推进，正面碾压 | 沉稳果决 | 坦克/装甲单位加成 |
| 空降突击 | 快速部署，机动决胜 | 年轻激进 | 步兵/直升机机动性加成 |
| 火力支援 | 远程压制，炮弹说话 | 理工气质 | 远程/炮兵单位伤害加成 |
| 特种作战 | 精英小队，技能驱动 | 实战派 | 特殊能力/技能冷却加成 |
| 合成作战 | 均衡配置，全面应对 | 参谋出身 | 全军均衡属性加成 |

---

## 四、被动 Buff

被动 Buff 全场生效，无需主动触发，为携带兵种或全军提供持续属性加成。

| 维度 | 说明 |
|---|---|
| 生效范围 | 全场生效，从战斗开始持续至结束 |
| 加成目标 | 视学派而定：可为特定兵种大类（如坦克）或全军 |
| 加成类型 | 攻击力、防御力、移动速度、攻速、军令回复速度等 |
| 数值成长 | 随将军等级提升，Buff 数值递增 |

---

## 五、主动技能

### 5.1 触发机制

| 维度 | 说明 |
|---|---|
| 出现方式 | 每次军令满条时必出现在四选一弹窗中（3 个随机兵种 + 1 个将军技能）；将军可拥有多个主动技能，每次四选一从已解锁技能中随机展示 1 个 |
| 军令消耗 | 释放时消耗军令（消耗值因技能而异） |
| 释放范围 | 覆盖全场，无半场限制 |
| 冷却 | 将军技能无冷却时间，但受军令条满触发频率限制 |

### 5.2 技能槽展示

| 展示位置 | 说明 |
|---|---|
| 将军详情面板 | 横向排列 5 个技能槽，展示将军拥有的技能 |
| 升级/升星弹窗 | 以标签页形式展示 3 个技能（技能1/技能2/技能3），可切换查看详情 |

### 5.3 技能类型

| 类型 | 示例效果 | 说明 |
|---|---|---|
| 增援部署 | 在指定位置召唤增援单位 | 快速补充前线兵力 |
| 区域轰炸 | 对指定区域造成范围伤害 | 清除敌方集群单位 |
| 战术 Buff | 为指定区域友军提供临时增益 | 改变局部战局 |
| 战场控制 | 烟雾/干扰/减速区域 | 控制敌方推进节奏 |
| 直接打击 | 对敌方大本营造成直接伤害 | 加速终结对局 |

---

## 六、部署策略

将军的部署策略直接决定局内大本营（军营）的基础属性，是开局前的重要决策维度。

| 属性 | 说明 |
|---|---|
| HP | 生命值 |
| 伤害 | 伤害值 |
| 护盾 | 护盾值 |
| 攻速 | 攻击速度 |
| 特殊效果 | 如反隐身等特殊能力 |

不同学派/品质的将军，各项属性侧重不同。

---

## 七、将军列表

### 7.1 列表展示

| 元素 | 说明 |
|---|---|
| 将军卡片 | 展示将军头像、名称、星级、所属学派 |
| 学派标识 | 装甲学院 / 空降突击 / 火力支援 / 特种作战 / 合成作战 |
| 佩带标记 | 当前佩带的将军显示"佩带"标记，同时只能佩带 1 个 |
| 排序 | 按星级品质降序排列 |
| 前往抽卡 | 跳转至商城·将军抽卡页面 |

### 7.2 初始将军

玩家在 Lv.1 开局时默认获得一名初始将军"前线指挥官"（合成作战学派），确保新手在解锁将军抽卡前拥有可用的将军。

---

## 八、将军详情

点击将军卡片弹出详情面板，展示完整信息：

| 面板元素 | 说明 |
|---|---|
| 基础信息 | 将军名称、星级品质、所属学派、当前等级/上限 |
| 被动 Buff | 全场生效的属性加成详情，展示当前等级数值 |
| 主动技能 | 技能名称、军令消耗值、效果描述、当前等级数值 |
| 部署策略 | HP、伤害、护盾、攻速、特殊效果数值 |
| 方案系统 | 5 套预设方案（方案一~五），每套方案包含 8 个兵种槽位 |
| 升级 | 消耗碎片 + 金币升级，提升 Buff 数值和技能效果 |
| 升星 | 消耗碎片 + 资源升星，解锁属性成长 |
| 佩带 | 已佩带显示"取消佩带"，未佩带显示"佩带" |

---

## 九、升级

### 9.1 升级机制

| 维度 | 说明 |
|---|---|
| 消耗资源 | 碎片 + 金币（格式如 666/999） |
| 升级效果 | 提升等级，增强被动 Buff 数值、主动技能效果、部署策略加成 |
| 等级上限 | 受将军品质和玩家等级限制 |
| 升级预览 | 展示当前属性与升级后属性对比，高亮变化量 |

### 9.2 升级确认

| 元素 | 说明 |
|---|---|
| 当前属性 | 当前等级的被动 Buff、技能效果、部署策略数值 |
| 升级后属性 | 下一级的对应数值，高亮变化量 |
| 消耗资源 | 碎片 + 金币的持有/需求数量（格式如 666/999） |
| 升级按钮 | 资源充足时可点击升级；资源不足时置灰 |

---

## 十、升星

| 维度 | 说明 |
|---|---|
| 消耗资源 | 碎片（如 3/4）+ 2 种资源 |
| 升星效果 | 解锁属性成长 |
| 属性值格式 | 基础值 + 加成值（如 1+9999） |

---

## 十一、登场机制

| 维度 | 说明 |
|---|---|
| 同时佩带 | 仅可登场 1 名将军 |
| 切换 | 在将军列表中选择其他将军，确认后替换当前佩带 |
| 卡组编成 | 在卡组编成界面中，将军槽位展示当前登场将军，点击可切换（详见 [养成与部队系统](../03_局外系统/养成与部队系统.md) 8.5 卡组编成） |
| 出战要求 | 必须登场 1 名将军才能出战 |
