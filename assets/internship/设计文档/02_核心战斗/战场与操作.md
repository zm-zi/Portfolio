## 一、场景布局

### 1.1 战场基础

| 项目 | 说明 |
|---|---|
| 视角 | 俯视角固定战场（类《皇室战争》） |
| 方向 | 竖屏战场，己方大本营在下，敌方在上 |
| 分界 | 屏幕中部以地形元素（河流/峡谷/废墟等）做自然分割 |
| 推进方向 | 兵种从部署点位出发，沿路线自动向敌方大本营推进 |

### 1.2 路线形状

地图路线形状共 6 种，由关卡决定：

| 路线类型 | 描述 | 战术特征 |
|---|---|---|
| 单通路 | 一条直线通道 | 正面硬刚，无侧翼空间 |
| Y 形 | 从己方出发后分叉为两条 | 己方选择进攻路线，敌方防守分兵 |
| X 形 | 两条路线交叉 | 中心交汇点为争夺焦点 |
| 倒 Y | 两条路线在敌方前合并 | 前期分兵，后期合流 |
| 环形 | 闭合环线 | 双向机动，包围与反包围 |
| 工字 | 两条平行路线+横向连接 | 可横向调动，纵深防御 |

### 1.3 大本营机制

大本营即军营，是局内战斗中的己方基地。军营不可独立升级，其局内属性（生命值、护盾值、反击伤害）完全由当前佩带的将军决定。

| 属性 | 说明 |
|---|---|
| 生命值（HP） | 军营基础血量，护盾被击破后开始扣除；HP 归零即战斗失败 |
| 护盾值 | 护盾层，存在时军营不损失真实血量；脱战后缓慢恢复 |
| 反击伤害 | 军营自动攻击进入射程的敌方单位，类似哨塔；攻击范围与攻速固定 |
| 外观变化 | 外观随等级变化，从简易阵地逐步升级为加固堡垒 |

**胜负判定**：摧毁敌方大本营即获胜；3 分钟时限结束时，比较双方大本营剩余血量（含护盾），多者胜。

### 1.4 释放范围

- 兵种从玩家拖拽部署的点位出发，沿所属路线自动推进
- 部署点位限于己方半场（大本营至中场分界线之间）
- 将军主动技能释放范围覆盖全场，无半场限制

## 二、UI 布局

### 2.1 军令条（兵力条）

| 项目 | 说明 |
|---|---|
| 上限 | 1000 |
| 回复速度 | 每秒 100（正常模式）；狂暴模式（121~180s）翻倍至每秒 200 |
| 显示位置 | 屏幕底部，大本营上方 |
| 满条触发 | 军令条满时弹出四选一弹窗，游戏暂停（PVE/异步PVP）或进入时缓（实时PVP） |

### 2.2 选兵框（四选一弹窗）

| 项目 | 说明 |
|---|---|
| 触发条件 | 军令条满 1000 |
| 内容 | 从 8 个携带兵种中随机抽取 3 个 + 当前将军主动技能 = 共 4 个选项 |
| 弃选 | 消耗 100 军令跳过本轮，不部署任何单位 |
| 随机性 | 每局可用兵种与技能组合不同，避免固定套路 |

## 三、操作流程

### 3.1 PVE / 异步 PVP 操作流程

```
军令增长（每秒 100）
    ↓
军令满 1000 → 触发四选一弹窗（游戏暂停）
    ↓
玩家选择：部署兵种 / 释放将军技能 / 弃选
    ↓
兵种自动沿路线进攻 → 军令继续增长
    ↓
循环至 3 分钟结束或一方大本营被摧毁
```

- 0~120s：正常模式，军令回复速度 100/秒
- 121~180s：狂暴模式，军令回复速度翻倍至 200/秒

### 3.2 实时 PVP 时缓机制

| 项目 | 说明 |
|---|---|
| 触发条件 | 军令条满 1000 |
| 时缓效果 | 游戏速度降至 20%，持续 5 秒 |
| 作用 | 代替 PVE 的暂停机制，为双方提供选兵决策窗口 |
| 双方同步 | 双方同时进入时缓状态，保证公平性 |

## 四、战斗系统

### 4.1 战斗规则

| 规则 | 说明 |
|---|---|
| 自动战斗 | 兵种部署后自动沿路线向敌方大本营推进，途中自动攻击遭遇的敌方单位 |
| 目标优先级 | 兵种优先攻击射程内最近敌方单位；无敌方单位时攻击大本营 |
| 地形交互 | 兵种移动受路线约束，不同地形影响移动速度与视野 |
