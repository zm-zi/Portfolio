## 一、设计概述

### 1.1 文档定位

本文档为"重返安伯莱"兵种系统的**细分框架设计**，在五大兵种大类（步兵、坦克、车辆、直升机、建筑）基础上拆分为子类型，形成完整战术职能矩阵。不涉及具体数值，仅搭建分类框架和属性维度模板。

### 1.2 设计方法论

两套方法论来源：

- **属性维度框架**借鉴《勇猛之路：二战》（Road to Valor: World War II）的兵种数据体系——每个兵种拥有品质、军令消耗、HP、部署位置、移动速度、人数、武器、射程、多类型伤害矩阵、攻速、特殊能力、王牌能力等完整属性维度。
- **兵种题材与装备**参考《Broken Arrow》（断箭）的现代军事装备分类——六大兵种专精体系（侦察、步兵、战斗载具、支援、直升机、战机），涵盖 M1A2 Abrams、Stryker 车族、AH-64E Apache、HIMARS 等大量现代装备。

### 1.3 兵种分类总览

| 大类  | 子类型数量 | 子类型                                         | 设计定位                   |
| --- | ----- | ------------------------------------------- | ---------------------- |
| 步兵  | 10    | 步枪班、反坦克小组、防空小组、机枪组、狙击手、特种部队、工兵、迫击炮班、医疗兵、重装组 | 地面作战主力，功能分化最细的大类       |
| 坦克  | 5     | 主战坦克、轻型坦克、坦克歼击车、喷火/特种坦克、重型坦克                | 装甲突击核心，正面战场支配者         |
| 车辆  | 7     | 步兵战车、装甲运兵车、侦察车、自行火炮、多管火箭炮、防空车、反坦克导弹车        | 机动支援平台，运兵/火力/防空/后勤     |
| 直升机 | 4     | 武装直升机、运输直升机、侦察直升机、隐形直升机                     | 空中机动与火力，三维战场关键变量       |
| 建筑  | 6     | 火力阵地、防空阵地、战术中心、生产设施、补给设施、陷阱/障碍              | 固定防御/生产/支援/战术支援，战场控制节点 |

> 总计 32 个子类型，覆盖陆空固定四个维度，为后续 20 个首批单位（未来扩充至 40）提供充足的分类空间。

### 1.4 品质体系

| 品质 | 标识 | 定位 |
| ---- | ---- | ---- |
| 常规 | 白 | 基础单位，低费高可用，卡组填充主力 |

## 二、属性维度框架

所有兵种子类型共享以下属性维度体系，后续数值设计阶段填充具体数值。

### 2.1 通用属性

| 维度    | 说明                            |
| ----- | ----------------------------- |
| 分类路径  | 格式：大类 > 子类型 > 具体单位名称          |
| 品质    | 常规 / 精锐 / 特种 / 战略             |
| 军令消耗  | 部署所需军令消耗量                     |
| HP    | 基础生命值                         |
| 部署位置  | 定义兵种的可释放范围：后方进场路 / 任意进场路 / 空降 / 友军区域。释放时玩家拖拽至该范围内的任意指定点位（非固定出击点），范围外无效并回弹 |
| 部署时间  | 所有兵种释放后均需经历部署时间，从指令下达到单位可行动的时间（不同兵种数值不同，无立即部署） |
| 移动速度  | 非常慢 / 慢 / 普通 / 快 / 非常快        |
| 人数/乘员 | 步兵为人数，载具为乘员数                  |
| 主武器   | 主要攻击手段的名称与描述                  |
| 攻速    | 攻击间隔                          |
| 射程    | 攻击距离                          |
| 打击面   | 可造成伤害的大类目标（步兵/车辆/坦克/建筑/直升机）   |
| 特殊能力  | 隐身、反隐、士气、布雷、治疗等               |
| 王牌能力  | 升级至王牌后解锁的独特能力                 |
| 武器效果  | 附加状态效果（士气下降、减速、燃烧等）           |

### 2.2 伤害矩阵（全部兵种）

每个兵种对五大目标类型拥有独立的伤害数值，形成完整的克制关系网络
### 2.3 装甲属性（坦克/车辆/直升机）

| 维度      | 说明                                |
| ------- | --------------------------------- |
| 装甲类型    | 无甲 / 轻甲 / 中甲 / 重甲                 |
| 附加装甲 HP | 额外防护层，需先击穿才能伤及本体                  |
| 装甲升级选项  | ERA（爆炸反应装甲）、格栅装甲、陶瓷装甲、APS（主动防御系统） |

### 2.4 建筑专属属性

| 维度    | 说明              |
| ----- | --------------- |
| 维持时间  | 建筑存在时长，到期自毁     |
| 部署限制  | 友军区域 / 任意位置     |
| 持续效果  | 建筑存在期间提供的增益或产出  |
| 部署时安装 | 部署时自动附带的地雷、障碍物等 |

### 2.5 直升机专属属性

| 维度   | 说明                |
| ---- | ----------------- |
| 飞行速度 | 悬停 / 慢速 / 中速 / 快速 |
| 载员量  | 可运输的步兵数量          |
| 武器挂载 | 可选武器配置方案          |
| 电子对抗 | 热诱弹、ECM、雷达隐身等     |
