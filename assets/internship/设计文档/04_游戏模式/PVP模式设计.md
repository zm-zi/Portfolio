# PVP 模式设计

| 版本 | v1.0.0 |
| 日期 | 2026-07-20 |

---

## 一、模式概述

PVP 模式分为**异步天梯**和**实时约架**两种子模式，在基地 Tab 中统一入口。PVP 不消耗体力，保证竞技和社交功能不受体力限制。

| 维度 | 异步天梯 | 实时约架 |
|---|---|---|
| 类型 | 异步 PVP（AI 托管防守方） | 实时 PVP（双方同时在线） |
| 数值 | 不统一（玩家养成属性生效） | 可选统一（公平模式可选） |
| 解锁等级 | Lv.6 | Lv.8 |
| 选兵机制 | 军令满条时暂停 | 军令满条时触发时缓（20% 速度，5 秒） |
| 单局时长 | 3 分钟（180 秒） | 3 分钟（180 秒） |

---

## 二、异步天梯

### 2.1 排名挑战制

异步天梯采用**排名挑战制**，玩家挑战天梯排名在自己之前的对手，胜利后与对手交换排名。

| 维度 | 说明 |
|---|---|
| 匹配范围 | 系统展示排名在自己之前的 N 名玩家（N 可配置，建议 3-5 名） |
| 挑战方式 | 选择目标对手后，进入异步战斗（对手由 AI 托管防守） |
| 防守方 | 被挑战方无需在线，系统使用其当前出战卡组由 AI 托管 |
| 排名交换 | 挑战胜利则双方排名互换；挑战失败排名不变 |
| 刷新对手 | 消耗钻石可刷新对手列表 |
| 战斗消耗 | 不消耗体力 |

### 2.2 数值不统一

天梯中玩家养成属性（兵种等级、将军等级）全部生效，不进行数值统一。战力数值（8 兵种 + 1 将军综合战力）在对手列表中展示，供玩家评估挑战难度。

### 2.3 天梯结算

| 维度 | 说明 |
|---|---|
| 日结算 | 每日按排名区间发放奖励（金币、钻石） |
| 赛季结算 | 每赛季（约 1 个月）按排名区间发放赛季奖励（钻石、限定头像框等） |
| 首次排名奖励 | 首次达到特定排名区间时发放一次性钻石奖励 |

---

## 三、实时约架

### 3.1 时缓机制

实时 PVP 中，双方军令条满时触发全局限速机制——**时缓**，代替 PVE 的暂停：

| 维度 | 说明 |
|---|---|
| 触发时机 | 军令达到上限（1000）时触发 |
| 时缓效果 | 全局速度降至 20%，持 5 秒 |
| 期间操作 | 玩家在时缓期间从四选一（3 兵种 + 1 将军技能）中选择部署 |
| 时缓结束 | 5 秒后自动恢复 100% 速度，或玩家提前完成选择后恢复 |
| 连锁触发 | 若双方同时军令满条，时缓效果一致，不叠加 |

### 3.2 对战入口

| 入口 | 说明 |
|---|---|
| 好友约架 | 在好友列表中选择在线好友，发起实时 PVP 邀请 |
| 房间对战 | 创建或加入对战房间，通过房间码邀请玩家 |

### 3.3 数值模式

| 模式 | 说明 |
|---|---|
| 自由模式 | 玩家养成属性全部生效（数值不统一） |
| 公平模式 | 双方兵种/将军等级统一至预设等级（数值统一，仅考验战术与操作） |

公平模式仅限实时约架，异步天梯不支持数值统一。

## 四、勋章与军衔系统

### 4.1 勋章积累

| 维度 | 说明 |
|---|---|
| 勋章获取 | 实时约架胜利获得勋章，失败不扣除勋章 |
| 勋章计算 | 对手军衔越高，胜利获得勋章越多 |
| 军衔晋升 | 勋章累计达到阈值后晋升军衔 |

---

## 五、排行榜

### 5.1 天梯排行榜

| 维度 | 说明 |
|---|---|
| 排行依据 | 天梯排名（数值来自异步天梯的排名交换系统） |
| 展示内容 | 排名、玩家头像、昵称、军衔、战力、所属军团 |
| 刷新频率 | 实时更新 |
| 自我定位 | 高亮显示当前玩家所在行，方便快速定位 |

### 5.2 排行榜类型

| 排行榜 | 说明 |
|---|---|
| 天梯总榜 | 全服天梯排名 |
| 军团排行 | 军团内成员天梯排名 |
| 好友排行 | 好友间天梯排名 |
| 赛季排行 | 当前赛季专属排名（赛季结束时重置） |

---

## 六、战斗结算

PVP 战斗结束后展示结算界面：

| 结算元素 | 说明 |
|---|---|
| 胜负判定 | 胜利/失败，展示双方大本营剩余血量 |
| 排名变化 | 天梯排名变化（上升/不变） |
| 勋章变化 | 实时约架获得的勋章数（天梯不涉及勋章） |
| 奖励列表 | 金币、经验（无论胜负均有基础奖励） |
| 操作入口 | 返回基地 / 再来一局 / 查看对手信息 |
