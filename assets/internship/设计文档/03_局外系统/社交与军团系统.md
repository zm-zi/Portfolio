## 一、军团模块

### 1.1 功能定位

军团模块是游戏的社交核心，提供工会功能。玩家可创建或加入军团，与军团成员互动、捐赠兵种碎片、发起军团约架。军团 Tab 在玩家等级达到 Lv.5 后解锁。

### 1.2 军团创建与加入

**未加入军团时**

显示军团列表和创建军团入口：

| 元素 | 说明 |
|---|---|
| 搜索 | 按军团名称或 ID 搜索 |
| 创建 | 消耗 300 钻石创建军团，设置名称、公告、入团条件 |
| 推荐军团 | 系统推荐未满员的军团，展示军团名、等级、人数、战力要求 |
| 申请加入 | 满足战力要求可申请，军团长/军官审批后加入 |
| 军团信息 | 已加入军团时显示军团摘要 |

**创建军团**

| 设置项 | 说明 |
|---|---|
| 军团名称 | 2-8 字，不可重复 |
| 军团公告 | 最多 100 字，展示军团规则和目标 |
| 入团条件 | 最低战力要求、是否需要审批 |
| 军团徽章 | 从预设徽章库中选择 |

### 1.3 军团互动

**军团主页**

已加入军团后，军团 Tab 显示军团主页：

| 功能 | 说明 |
|---|---|
| 成员列表 | 展示军团成员（军团长/军官/成员），显示在线状态、等级、军衔、战力、本周捐赠数 |
| 军团聊天 | 军团内文字聊天，支持发送兵种/将军卡片分享 |
| 约架 | 发起军团内部约架，与军团成员进行实时 PVP 切磋 |
| 设置 | 军团长/军官可修改公告、审批申请、踢出成员、提升/降级成员 |

**兵种碎片捐赠**

| 维度 | 说明 |
|---|---|
| 捐赠请求 | 成员可发起碎片捐赠请求，指定需要的兵种碎片类型和数量 |
| 捐赠响应 | 其他成员可点击请求进行捐赠，每次捐赠获得军团积分和经验 |
| 捐赠限制 | 每日可发起 1 次请求，可捐赠 3 次；捐赠碎片从自身持有量中扣除 |
| 军团宝箱 | 军团总捐赠数达到阈值后解锁军团宝箱，全员可领取 |

**军团等级与奖励**

| 维度 | 说明 |
|---|---|
| 军团经验 | 成员捐赠、约架、日常活跃贡献军团经验 |
| 军团等级 | 经验积累升级，提升军团人数上限和宝箱品质 |
| 军团宝箱 | 定期发放，等级越高宝箱品质越好，包含金币、钻石、碎片 |

### 1.4 军团约架

军团与军团之间可发起约架切磋，进入实时 PVP 对战。实时约架的战斗机制（时缓、选兵、胜负判定等）详见 [PVP 模式设计](../04_游戏模式/PVP模式设计.md) 第三章。

| 维度 | 说明 |
|---|---|
| 发起方式 | 军团长/军官可向其他军团发起约架邀请 |
| 参与人数 | 双方各指定若干成员参与对战 |
| 对战形式 | 实时 PVP，双方同时在线进行 3 分钟实时战斗 |
| 解锁等级 | Lv.8 |

## 二、好友系统

### 2.1 好友系统

| 功能 | 说明 |
|---|---|
| 好友列表 | 展示好友的在线状态、头像、昵称、等级、军衔，支持按在线状态排序 |
| 添加好友 | 通过搜索玩家 ID/昵称添加、军团内添加、对战后发送好友申请 |
| 好友申请 | 收到好友申请时好友按钮显示红点，可接受/拒绝 |
| 好友互动 | 好友约架（跳转基地·实时约架）、赠送体力（每日可赠送 5 人，每人 1 点）、查看好友进度 |
| 好友推荐 | 推荐同等级段、同军团、近期对战过的玩家 |
| 好友上限 | 初始 30 人，随玩家等级提升增加（每 5 级 +5 人） |
