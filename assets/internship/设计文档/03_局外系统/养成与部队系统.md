## 一、部队模块

### 1.1 功能定位

部队模块是局外养成的核心，整合军营、兵种管理、将军管理和卡组编成四大功能。玩家在此管理已收集的兵种和将军，进行升级、解锁、佩带等操作，并编成出战卡组（8 兵种 + 1 将军）。军营不可独立升级，其局内属性由当前佩带的将军决定。部队 Tab 默认开放，是新手最先接触的养成入口。

### 1.2 军营

#### 1.2.1 功能定位

军营是局内战斗中的己方基地，也是部队防御的核心。军营**不可独立升级**，其局内属性（生命值、护盾值、反击伤害）完全由当前佩带的将军决定。不同学派/品质的将军，三项属性加成侧重不同（详见 [将军系统设计](../02_核心战斗/将军系统设计.md) 第六章部署策略）。

#### 1.2.2 局内表现

军营的局内表现与 [战场与操作](../02_核心战斗/战场与操作.md) 第一章大本营机制一致：

| 局内表现 | 说明 |
|---|---|
| 外观 | 军营外观随将军品质/等级变化，品质越高建筑越完整、防御设施越丰富（从简易阵地逐步升级为加固堡垒） |
| 护盾机制 | 护盾未被击破时，军营不损血；护盾被击破后进入真实血量阶段；护盾在脱战后缓慢恢复 |
| 反击 | 军营自动攻击进入射程的敌方单位，伤害值由将军的部署策略决定 |
| 被摧毁 | 军营 HP 归零即战斗失败，敌方获胜 |

### 1.3 兵种管理

#### 1.3.1 兵种列表

按五大类分类展示已收集的兵种，支持按类别筛选和品质筛选。

| 元素 | 说明 |
|---|---|
| 分类筛选 | 全部/步兵/坦克/车辆/直升机/建筑，与 [兵种框架设计](../02_核心战斗/兵种框架设计.md) 五大类一致 |
| 兵种卡片 | 展示兵种缩略图、名称缩写、品质边框颜色（白/蓝/紫/金） |
| 佩带标记 | 已佩带在当前卡组中的兵种卡片右上角显示"佩带"图标 |
| 锁定状态 | 未解锁兵种显示灰色锁定，点击可查看解锁条件 |
| 收集进度 | 底部显示已收集数量/总数和已佩带数量 |

#### 1.3.2 兵种详情

点击兵种卡片弹出兵种详情面板，展示完整属性和操作按钮。

| 面板元素 | 说明 |
|---|---|
| 基础信息 | 名称、品质（星级标识）、分类路径（大类>子类型），与 [兵种框架设计](../02_核心战斗/兵种框架设计.md) 格式一致 |
| 兵种立绘 | 兵种 3D 渲染图（与 assets 目录中的素材一致） |
| 属性面板 | HP、移速、攻速、射程等通用属性，与 [兵种框架设计](../02_核心战斗/兵种框架设计.md) 2.1 节属性维度框架一致 |
| 伤害矩阵 | 对五大目标类型的伤害数值（步兵/车辆/坦克/建筑/直升机），与 2.2 节伤害矩阵一致 |
| 特殊能力 | 隐身、反隐、士气、布雷、治疗等，与 2.1 节特殊能力维度一致 |
| 装甲属性 | 坦克/车辆/直升机显示装甲类型和附加装甲（衔接 2.3 节装甲属性） |
| 升级 | 消耗碎片 + 金币升级，当前等级/上限等级展示 |
| 佩带 | 已佩带则显示"取消佩带"，未佩带且卡组有空位则显示"佩带" |

#### 1.3.3 兵种升级

点击"升级"按钮后弹出升级确认面板：

| 元素 | 说明 |
|---|---|
| 当前属性 | 当前等级的 HP、伤害等核心数值 |
| 升级后属性 | 下一级的 HP、伤害等核心数值，高亮变化量 |
| 消耗资源 | 兵种碎片（需求数量/持有数量）+ 金币（需求数量/持有数量） |
| 升级按钮 | 资源充足时可点击升级；资源不足时置灰，点击弹出"前往商城"跳转 |

#### 1.3.4 兵种解锁

未解锁兵种点击后显示解锁条件：

| 解锁方式 | 说明 |
|---|---|
| 关卡解锁 | 通过 PVE 关卡进度解锁（衔接 [PVE模式设计](../04_游戏模式/PVE模式设计.md) 1.6 节兵种解锁节奏），显示"通关关卡 X-X 解锁" |
| 碎片收集 | 收集足够碎片后解锁，显示"收集 X/X 碎片解锁"，碎片来源为宝箱、商城、任务 |

### 1.4 将军管理

#### 1.4.1 将军列表

展示已拥有的将军，按星级排序。玩家在 Lv.1 开局时默认获得一名初始将军（"前线指挥官"），确保新手在解锁将军抽卡前拥有可用的将军。

| 元素 | 说明 |
|---|---|
| 将军卡片 | 展示将军头像、名称、星级、所属学派 |
| 学派 | 装甲学院/空降突击/火力支援/特种作战/合成作战 |
| 佩带标记 | 当前佩带的将军显示"佩带"标记，同时只能佩带 1 个 |
| 前往抽卡 | 跳转至商城·将军抽卡页面 |

#### 1.4.2 将军详情

点击将军卡片弹出详情面板：

| 面板元素 | 说明 |
|---|---|
| 基础信息 | 将军名称、星级品质、所属学派、当前等级/上限 |
| 被动 Buff | 全场生效的属性加成，为携带兵种或全军提供增益 |
| 主动技能 | 与兵种共同进入军令满条时的四选一弹窗（3 兵种 + 1 将军技能），消耗军令释放；展示军令消耗值和效果描述 |
| 部署策略 | 直接决定军营（大本营）的血量、护盾和攻击 |
| 升级 | 消耗将军碎片 + 金币升级，提升 Buff 数值和技能效果 |
| 佩带 | 同时只能佩带 1 个将军 |

### 1.5 卡组编成

卡组编成界面整合兵种和将军的出战配置，是进入战斗前的最终确认环节。

| 元素 | 说明 |
|---|---|
| 将军槽 | 展示当前佩带将军，点击可切换至将军列表选择 |
| 兵种槽 | 8 个槽位展示当前佩带的 8 个兵种，点击空槽位弹出兵种列表选择 |
| 拖拽调整 | 支持拖拽兵种卡片调整槽位顺序（仅影响展示顺序，不影响战斗） |
| 总战力 | 8 兵种 + 1 将军的综合战力数值，用于天梯匹配参考 |
| 平均军令消耗 | 8 个兵种的平均军令消耗值，帮助玩家评估卡组节奏 |
| 阵容平衡 | 展示当前卡组的兵种大类分布，帮助玩家评估阵容搭配 |
| 推荐编成 | 系统根据当前关卡/对手推荐合适的兵种搭配方案 |
| 保存 | 保存当前编成为出战卡组，返回部队主页 |

**编成规则**：

- 8 兵种槽位必须全部填充才能出战
- 1 将军槽必须选择 1 个将军才能出战（Lv.1 开局默认拥有初始将军"前线指挥官"，确保新手可正常编成出战）
- 支持保存多套预设卡组方案，快速切换不同战术搭配
