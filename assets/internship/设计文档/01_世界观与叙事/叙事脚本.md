## 一、叙事节点表

世界观通过以下叙事节点向玩家呈现，不依赖大段文本阅读。

### 1.1 关卡简报

每关开场 2~3 句指挥官通讯，交代当前关卡目标与战术背景，营造前线氛围。

| 要素 | 说明 |
|---|---|
| 触发时机 | 关卡加载完成后、战斗开始前 |
| 呈现形式 | 指挥官通讯面板（对讲机/无线电界面风格），2~3 句简短对白 |
| 内容要素 | 当前关卡战术目标、敌情简报、地形提示 |
| 文案风格 | 军事通讯口吻，简洁直接，避免冗长铺垫 |

**文案模板**：

> "指挥官，前方哨站报告敌方巡逻队活动频繁。清除该区域，为后续部队打开通道。"
>
> "侦察显示敌军在此部署了反装甲单位。注意坦克推进路线，保持步兵掩护。"

### 1.2 Boss 战前奏

每章末关的 Boss 战前，通过敌方通讯截获或情报简报揭示据点指挥官身份与动机，建立 Boss 战叙事重量。

| 要素 | 说明 |
|---|---|
| 触发时机 | 章节末关（Boss 关）战斗开始前 |
| 呈现形式 | 敌方通讯截获界面 / 情报官简报面板 |
| 内容要素 | Boss 身份、背景、在安博莱政权中的角色、与联防军的历史关联 |
| 叙事功能 | 为 Boss 赋予人格化特征，让每章 Boss 不仅是数值挑战，更是叙事节点 |

**文案模板**：

> **[情报截获]** "……第三工业区仍在我方控制下。告诉联防军那群残兵，这里的每一台机器都在为他们生产棺材。"
> —— 工业带指挥官，"铁砧"瓦西里

> **[情报官简报]** "指挥官，这是安博莱外围防线的最后一道屏障。负责防守的是原联防军装甲营副营长——三年前撤退时被俘，之后叛变。他了解我们的战术。"

### 1.3 章节过渡

章节间通过静态插画 + 简短旁白，标记战略推进，呼应"归途"情感线。

| 要素 | 说明 |
|---|---|
| 触发时机 | 每章末关完成后，进入下一章之前 |
| 呈现形式 | 全屏静态插画（关键帧风格）+ 2~3 句旁白文字 |
| 内容要素 | 战略推进总结、离安博莱的距离、士兵情绪状态 |
| 叙事功能 | 为章节划分节奏，强化"归途"情感积累 |

**文案模板**：

> **[第 1 章 → 第 2 章过渡]**
> "边境地带已肃清。前方是安博莱的农业腹地——三年前，我们曾在这里建立过补给站。如今，那些仓库里堆满了敌人的物资。"
> 
> 插画：部队穿过边境检查站，远方是连绵的麦田与零星的废弃农舍。

### 1.4 关卡内环境叙事

通过地图物件与场景细节传递"战后三年"氛围，无声叙事。

| 要素 | 说明 |
|---|---|
| 触发时机 | 持续存在（关卡内场景） |
| 呈现形式 | 地图场景物件：标语、残骸、建筑状态、废弃装备 |
| 内容要素 | 被占领城市的生活痕迹、三年前战役的遗留物、联防军制式装备被敌方使用的证据 |
| 叙事功能 | 无需文字，通过视觉传达"这是我们的城市，他们开着我们的坦克" |

**场景物件示例**：

| 章节 | 场景物件 | 叙事信息 |
|---|---|---|
| 第 1 章 边境地带 | 废弃的联防军哨站、被涂改的界碑 | 我方曾控制此区域，现已沦陷 |
| 第 2 章 农业带 | 弹孔密布的农舍、翻倒的联防军补给车 | 平民撤离后的痕迹，战争对农业的破坏 |
| 第 3 章 工业带 | 仍在运转的工厂、联防军武器拆解线 | 敌方利用缴获装备扩充军力 |
| 第 4 章 交通枢纽 | 被炸毁的铁路桥、翻覆的装甲列车 | 关键交通线被切断，孤立安博莱 |
| 第 5 章 安博莱外围 | 焦土化的郊外废墟、燃烧的油桶 | 城破在即，敌军做最后抵抗 |
| 第 6 章 安博莱城区 | 布满弹孔的原联防军指挥部大楼 | 三年前撤退的起点，如今归途的终点 |

### 1.5 新兵种解锁演出

新兵种解锁时通过简短演出强化获得感和叙事关联。

| 要素 | 说明 |
|---|---|
| 触发时机 | 兵种首次解锁时（关卡解锁 / 碎片收集解锁） |
| 呈现形式 | 兵种展示动画 + 1~2 句装备说明旁白 |
| 内容要素 | 兵种在战场上的角色定位、装备来源说明 |
| 叙事功能 | 将兵种解锁与世界观连接——"这是三年前留下的装备，现在归我们了" |

**文案模板**：

> "MBT-4 主战坦克——装甲学院的主力装备。三年前撤退时，我们留下了太多这样的好家伙。现在，是时候把它们开回去了。"

## 二、章节情绪弧线

> 详细情绪弧线见 [世界观设定](./世界观设定.md) 第八节"基调"。

v1.0"归途行动"的情绪弧线走向：坚定 → 焦灼 → 惨烈 → 决绝 → 压抑 → 光荣。整体呈"先抑后扬"结构——前 5 章积累压力与牺牲，第 6 章释放为光荣与解脱。

---

## 三、设计基调

> 视觉基调和色调详情见 [世界观设定](./世界观设定.md) 第八节。

**"战后三年"**——破损但不荒芜，被占领但未被摧毁。整体色彩从冷色调（军绿/灰）逐步过渡到暖色调（日出暖色），章节递进中用日出暖色隐喻"离归途越来越近"。

### 3.1 情绪递进

| 阶段 | 章节范围 | 情绪特征 | 叙事手法 |
|---|---|---|---|
| 起始 | 第 1~2 章 | 正面推进，士气高昂 → 遭遇阻力 | 关卡简报以战术指令为主，少量环境叙事 |
| 转折 | 第 3~4 章 | 代价显现，伤亡累积，决心加固 | Boss 战前奏开始揭示敌方指挥官背景，章节过渡强调牺牲 |
| 高潮 | 第 5~6 章 | 兵临城下，压抑爆发，光荣收尾 | 关卡内环境叙事密集，最终 Boss 战前奏为情绪最高点 |

## 四、叙事设计原则

| 原则 | 说明 |
|---|---|
| 轻量呈现 | 不依赖大段文本阅读，每个叙事节点控制在 2~3 句 |
| 环境叙事优先 | 能用场景物件传达的，不用文字 |
| 军事通讯风格 | 所有文字以指挥官通讯/情报简报形式呈现，保持世界观一致性 |
| 情感逐步积累 | "归途"情感线贯穿 6 章，不急于在早期释放 |
| 敌方人格化 | 敌方指挥官不是面目模糊的"敌人"，而是有背景、有动机的角色 |
