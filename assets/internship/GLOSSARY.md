## 二、系统术语

| 术语 | 定义 |
|---|---|
| 军令 | 战斗中随时间自动增长的资源，上限 1000，用于部署兵种和释放将军技能 |
| 时缓 | 实时 PVP 中军令满时触发的全局 20% 速度减速机制，持续 5 秒 |
| 部署位置 | 兵种的可释放范围属性：后方进场路 / 任意进场路 / 空降 / 友军区域 |
| 可释放范围 | 由部署位置决定的拖拽定点区域，玩家拖拽兵种至范围内任意点位完成部署 |
| 部署时间 | 兵种从指令下达到单位可行动的时间 |
| 狂暴模式 | 121~180 秒期间兵力条回复速度翻倍 |
| 大本营 | 双方基地，拥有护盾值 + HP，护盾未破前不损血 |
| 护盾值 | 大本营的额外防护层，可随时间缓慢恢复 |
| 品质 | 兵种/将军的稀有度分级：常规(白) / 精锐(蓝) / 特种(紫) / 战略(金) |
| 学派 | 将军的战术学派分类：装甲学院 / 空降突击 / 火力支援 / 特种作战 / 合成作战 |
| 章节-序号 | 关卡编号格式，如 1-3 表示第一章第三关 |
| 一章一图 | 每章 1 张固定地图，章节内关卡通过路径微调、敌方配置变化等手段差异化 |
| 扫荡 | 已三星通关的关卡无需手动战斗，消耗体力直接获取重复通关奖励 |
| 等级礼包 | 按等级节点（Lv.1/5/10/.../60）发放的包含嵌套机制的道具包，打开后获得奖励+下一档礼包 |
| 军衔 | 玩家账户等级对应的称号（列兵→元帅，共16级），区别于 PVP 天梯段位 |
| 聚焦指引 | 新功能解锁后主界面目标入口高亮发光+半透明遮罩的引导效果 |
| 个人信息与设置面板 | 主界面左上角头像区点击弹出的三Tab面板（信息/通知/设置） |
| 星级横条 | PVE关卡卡片上展示三星评价和对应宝箱的横向条状UI组件 |
| 升星 | 将军升星机制，消耗碎片+资源提升星数，解锁属性成长 |
| 招募券 | 将军招募专用资源，单抽100/十连1000 |
| 方案 | 将军详情面板中的预设兵种配置，5套方案各含8个兵种槽位 |
| 军团贡献 | 军团成员通过捐赠、任务等获得的兑换货币 |
| 食堂 | 基地中的体力产出建筑 |

## 三、地形术语

| 术语 | 定义 |
|---|---|
| 峡谷 | 隘口收窄、崖壁掩护、曲射受限的地形机制 |
| 河流 | 桥梁争夺、涉水、两栖机动的地形机制 |
| 丛林 | 步兵隐身、载具减速、可被引燃的地形机制 |
| 隘口 | 峡谷地形中宽度仅 2-3 单位的狭窄通道 |
| 浅滩 | 河流地形中步兵可涉水通过的路径点 |
| 路线形状 | 地图的路径拓扑：单通路 / Y 形 / X 形 / 倒 Y / 环形 / 工字 |
