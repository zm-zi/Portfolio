# 三角洲行动 产品拆解案

---

## 一、绪论：腾讯战术射击游戏又一现象级大作

### 1.1 报告综述与研究视角

本拆解按旨在个人求职游戏策划岗位编写的初步产品拆解案。报告立足于2025年下半年，以及2026年5月份之前的《三角洲行动》的运营数据与版本迭代路径，采用逆向工程与数据考古相结合的方法，对该产品的核心玩法循环、经济系统架构、关卡设计哲学及全球化发行策略进行穷尽式分析。作为琳琅天上团队在“下一代战术射击”领域的旗舰产品，该作不仅承载着激活经典IP的历史使命，更是腾讯在《和平精英》与《穿越火线》之后，试图通过“玩法融合”策略攻占硬核FPS市场的关键落子。本报告将重点剖析其如何在一个客户端内平衡“烽火地带”（生存撤离）、“全面战场”（大规模攻防）与“黑鹰坠落”（经典PVE战役）三种截然不同的体验，并针对2025年下半年和2026年上旬出现的舆情危机提出个人见解。

### 1.2 市场定位与宏观背景

2025年是全球射击游戏市场从"单一玩法"向"复合体验"转型的分水岭，也是腾讯射击品类全面爆发的一年。根据腾讯2025年全年财报显示，游戏业务总收入达到2416亿元，同比增长22%，其中国际市场收入首次突破100亿美元大关，同比增长33%。这一增长曲线的核心引擎正是射击品类——据伽马数据统计，射击类游戏以仅7%的产品数量贡献了前100移动游戏18.29%的收入份额，全年增量超过百亿元。其中《三角洲行动》的表现尤为瞩目：2025年收入同比暴涨29倍，移动端累计收入突破5亿美元，9月DAU突破3000万，到2026年春节档更创下日流水历史峰值，国服DAU峰值突破5000万，正式从"新品爆款"跨入"长青游戏"行列。与此同时，"搜打撤"模式以3000万DAU的体量成为FPS增长最快的子品类，《无畏契约》系列月活突破5000万，《和平精英》除夕夜DAU突破9000万——腾讯已构建起行业最完整的FPS产品矩阵，正在推动射击品类在中国市场从20%的份额向全球平均35%的水平跃迁，这意味着至少存在数百亿元的增量空间。

## 二、核心机制拆解

### 2.1 烽火地带(搜打撤)

融合了MOBA元素的搜打撤游戏，三角洲行动和其他搜打车游戏最大的区别在于，他不想暗区突围和逃离塔克夫那样角色单调和硬核，更符合当代的游戏节奏和大众胃口，上手简单，新鲜感足。

#### 2.1.1 核心体验定位

这个模式给玩家带来的不仅由传统FPS游戏的竞技，对抗，还有生存，掠夺，紧张感，财富积累
"高风险决策下的紧张博弈感" —— 每一局都是一场关于"贪与怂"的心理拉扯。

具体拆解为三个体验关键词：

体验关键词|	对应设计	|玩家心理
紧张感	  |死亡永久失去装备 + 撤离点超载机制	|"我带了最好的装备，这局不能死"
决策感	  |搜 vs 打 vs 撤的实时判断	|"继续搜还是现在撤？那个脚步声是人机还是玩家？"
成就感	  |成功撤离后的物资变现 + 资产积累	|"这局赚了100万，值了！"



#### 2.1.2 核心循环（搜--打--撤）

准备阶段（仓库配装）
    ↓
入场（出生点分配）
    ↓
┌─────────────────────────────────┐
│  搜 → 遭遇 → 打 → 搜 → 判断 → 撤  │  ← 单局循环
└─────────────────────────────────┘
    ↓
撤离成功 → 物资变现 → 仓库积累 → 下一局配装
撤离失败 → 装备全失 → 从头再来

#### 2.1.3 环节拆解

「搜」—— 信息博弈与资源获取
地图中有固定物资刷新点 + 随机稀有物资（曼德尔砖）
不同难度地图（普通/机密/绝密）物资品质递增，风险同步递增
搜索过程本身就是一个"暴露位置"的风险行为

「打」—— 战术对抗与资源争夺
PvPvE：既要打AI巡逻队，又要防真人玩家小队
3人小队配合：兵种分工（突击/支援/侦察/工程）
击杀敌人可掠夺其装备，但战斗本身消耗弹药、护甲、血量

「撤」—— 风险管理的终极考验
多种撤离点类型：常规（常开）、概率（随机开放）、条件（需丢包/限重）、付费（花游戏币）
撤离超载机制：部分撤离点限制人数（如5人），超出者撤离失败
携带稀有物资（曼德尔砖）时位置全图暴露

#### 2.1.4 经济系统（哈夫币）

经济系统是烽火地带最重要的系统，经济系统是搜打撤模式的命脉，直接决定了游戏寿命，所有内容都是围绕着核心经济“哈夫币”展开的

收入：主要由对局获取物资撤离带出，其次由任务活动获取
支出：主要用于购买进入对局的装备，其次用于升级特勤处等基础设施

仓库（持久化） ←→ 单局（消耗+获取）
撤离：带入装备 + 搜索物资 + 成功撤离 → 存入仓库
失败：带入装备 + 搜集物资 + 撤离失败 → 全部丢失

存入仓库的物资可变卖为哈夫币，用哈夫币获取更强力的装备，提高撤离几率。

核心设计矛盾：

如果物资获取太容易 → 玩家很快"毕业"，失去游玩动力
如果物资获取太难 → 玩家频繁"破产"，挫败感过强
三角洲的做法：不同难度地图形成"梯度经济"，普通地图保本，机密/绝密地图高风险高回报

装备带入成本 vs 平均撤离收益
       成本          收益(估算值)
普通   0-50w         50w
机密   10w-300w      200w
绝密   55w-300w      500w

假设机密地图撤离率为40%，平均收益200万，平均成本50W万，则：

单局期望收益 = 200万 × 40% - 50万 × 60% = 80万 - 30万 = 50万
假设绝密地图撤离率为30%，平均收益500万，平均成本150万，则：
单局期望收益 = 500万 × 30% - 100万 × 70% = 150万 - 70万 = 80万
这说明绝密地图的期望收益是机密地图的1.6倍，但风险（方差）远高于机密地图，符合"高风险高回报"的设计意图。

保险箱系统分析：

保险箱内的物资不会因撤离失败丢失。这个机制
大幅降低了死亡惩罚的挫败感
为新手提供了"保底"心理安全感
创造了"保险箱经济学"——玩家会优先把最值钱的东西放保险箱

破产保护机制：

零门槛进入普通地图获取物资，虽然收获少但是只需要付出时间成本即可，其他任务或或者活动等也会提供物资
物资刷新率与稀有度分布：与地图难度呈正相关，但是具体物资爆率是动态的，有固定物资点但是出货概率不固定，普遍说法分为个人爆率，容器爆率，与地图爆率。

通货膨胀控制：

增加入局所需战备值（装备价值），增加撤离难度等，但是每次调整都会引来玩家的不满，本质还是哈夫币的获取难度增加了。
这是三角洲的一大痛点，策划在开服的时候豪言仓库物资永久保存，导致通货膨胀容易出现，只能变相通过一些手段来控制。

问题： 经济通胀难以控制

我的方案： 引入"赛季远征"机制（参考ARC Raiders）——玩家达到一定等级后可选择重置进度，换取限定奖励和下赛季的增益Buff。这样：

硬核玩家有了长线目标（追求远征成就）
休闲玩家不用被迫重置（保留进度）
经济系统自然重置（参与远征的玩家清空仓库）
官方不需要"砍收益"来控制通胀（减少玩家反感）

护甲减伤曲线：

护甲收益确实有，但是在同级子弹下就是一两枪的差距，所有护甲收益并不高，玩家之间也流传出“穷什么都不能穷子弹”的说法

弹药经济：

这是游戏比较大的开支，子弹的消耗在高端对局可能会占到总消耗的一半甚至更多，这也导致游戏内与子弹有关的物品价格持高不下。

#### 2.1.5 战斗系统

干员机制：

非传统公平竞技，而是采用了每个干员都有自己的定位和技能，采用了MOBA元素，给游戏带来了更多的竞技性和可玩性。

兵种	定位	   	 战术价值
突击	近距离作战	 开路先锋，吸引火力
支援	团队续航	 降低团队生存压力
侦察	信息获取	 信息中枢，掌控战局
工程	防御/控制	 前线布控，区域控制

TTK（击杀时间）:

不同枪械不同子弹的TTK的区别比较大，以统计防具和子弹来说正常的TTK不会超过0.5S与传统的FPS游戏差不多，高级打低级甚至会达到0.2S以内，低级打高级则可能接近1S，这与传统的FPS游戏差距不大，上述只讨论正常打上半身。游戏中还存在一些比较特殊的子弹和，如肉蛋，专打四肢，TTK在0.4S左右，打头很多武器都是1-3枪就会死，不做计算。总的来说与传统FPS差别不大，但是该游戏的设定并非非常硬核，所以客观来看TTK稍微有些短，对新手比较友好，但是对老玩家，或者高战备入场的玩家来说，差距不容易放大。

#### 2.2.6 撤离系统

撤离点类型：
常规撤离点，特殊撤离点（丢包，负重，随机，任务，付费），拉闸撤离点。不同的撤离点出发的条件不同，随着地图难度增加，撤离点的数量也就要少，触发条件越苛刻。撤离是整个游戏最重要的环节，如果撤不出去，对局中的大部分努力都将白费。（保险箱内的物资不会因为撤离失败而丢失）

超载机制： "撤离超载机制是三角洲在2025年10月'共享监狱'事件后引入的设计。其核心意图是：通过限制撤离人数，恢复'搜打撤'模式的核心张力——'你死我活'的竞争关系。但这一设计的副作用是：它惩罚了所有玩家，而不仅仅是'共享监狱'的参与者。更优的设计可能是：在地图层面增加'合作撤离'与'竞争撤离'的分区，让不同偏好的玩家各得其所。"

#### 2.2.7 关卡拆解（航天基地）

作为烽火地带最热门的地图，他的设计也是颇具艺术的：
设计哲学："中心辐射型"——强制向心博弈
核心矛盾：所有玩家被逼向同一核心区，冲突不可避免
撤离机制：拉闸制（需激活撤离点），飞升（做任务），丢包撤离（丢弃背包，只能携带少量物资撤离）
核心体验：高压竞技，"最后一队活着出去"
核心设计意图：所有出生点分布在地图外围，所有高价值物资和撤离点集中在核心区。玩家必须向中心移动才能获取收益和撤离，这天然制造了"向心冲突"。

流派分析：
猛攻队（欧美打法）：购买最好的装备，进图不为吃东西，只为把全图的玩家清空。
正常玩家：正常购买装备，不是最好但也不差，能吃则吃，能打则打，常规玩法。
跑刀流：使用最廉价的装备，最低的成本进入地图，几乎没有战斗力，以搜索为主，眼观六路耳听八方，选择风险最低的撤离方案，以小博大。
单三：一个人带两个人或者三个人的装备，具备一打三过硬的实力，绝活哥的代表。
老鼠队：装备很差，寻找机会埋伏最后一队，窃取胜利果实。
自爆流：使用最廉价的装备，最低的成本进入地图，带着游戏最大的保险，保险塞满就自杀。

静音航天：指没有玩家敢开第一枪，一旦有两队玩家率先开战，可能全图的玩家听到了都会去劝架，然而得吃的只能是最后一对，充分演绎了螳螂捕蝉黄雀在后。

撤离方式：丢包撤（机密三人，绝密一人），飞升撤离（接取任务，等待时间或者完成任务即可撤离），拉闸撤离（拉蓝市和离心两个位置的闸在闸点）

总结：所有玩家的复活点均在地图的外围，而物资点，撤离点，都集中分布在核心区，进入核心区，可以刷卡走捷径，也可以绕路走免费的通道，所以玩家想要获取高价值物资，或者撤离需要去核心区，这也，核心区物资点丰富密集，高风险，高回报，是的航天基地这张地图的竞技性，可玩性，物资是所有游戏中最高的。整张图的构思都非常巧妙，让玩家对这张地图又爱又恨，基本上每局只能有一队或者两队能活着出去，但也因为撤离不容易，所以很多玩家都不愿先开战，导致最后可能进入大混战，以至于没有时间拉闸，导致没有一队可以撤离。它不像其他搜打撤游戏那样"搜完就跑"，而是制造了一个"你死我活"的终局博弈，极大地提升了对局的紧张感和戏剧性。

#### 2.2.8 设计亮点（个人见解）

亮点一：MOBA元素的干员设计，打破传统FPS游戏壁垒，使游戏可玩性更高，受众更广。
两点二：多种玩家玩法
玩家类型	    核心诉求	                  三角洲如何满足/未满足

#### 2.2.9 设计问题（个人见解）

2025年最值得分析的游戏设计案例：“共享监狱事件“

事件背景：玩家在最高难度地图"潮汐监狱"自发形成合作——选防御型干员"深蓝"，通过暗号确认友善后一起搜物资撤离
官方应对：10月5日紧急更新，撤离点限5人 + 深蓝防爆减伤从30%砍到10% + 持盾移速削弱
玩家反应：50万差评，收入暴跌，罢游运动
设计启示：玩家自发行为 vs 官方经济调控的根本矛盾——这是搜打撤品类的"无解难题"

为什么玩家会自发形成合作？（因为绝密地图风险太高，合作比对抗的期望收益更高）
官方的调控逻辑是什么？（维护经济系统的长期健康）
为什么玩家反应如此激烈？（感觉被"背刺"——官方教玩家怎么玩游戏）
如果你是策划，你会怎么处理？（先做出应急措施，暂时关闭监狱地图，内部开会商讨，做游戏调研，倾听玩家心声，寻找到一个玩家和开发商都能接受的折中做法）

外挂横行:作为一款免费游戏，制作外挂与使用外挂的成本极低，虽然腾讯有着全球最顶尖的技术但是并不能完全避免外挂现象，这也导致了玩家体验差，游戏开发商头疼的现象，其次三角洲有有偿跑刀（花钱找人给自己的号赚钱）和护航（请两个专业的打手保护自己清图爽吃撤离）现象，进一步促进了外挂产业。但是外挂对于三角洲来说并不完全是坏事，它可以很大程度减少通货膨胀这一现象，促进哈夫币消耗等。

#### 2.2.11 商业模式分析

三角洲是免费游戏 + 皮肤付费模式

皮肤对FPS游戏的影响（是否有Pay-to-Win争议？）
枪械与干员皮肤对公平竞技没有任何影响
但是刀皮和通行证对对局有轻微的失衡影响，刀的出刀速度和伤害，付费的普遍比免费的要好，虽然PVP很少用到刀，但是还是也少数时候是会用到的。其次是通行证，付费的会赠与玩家大量物资与一个赛季的2X3的保险箱，会拉开付费玩家与普通玩家的贫富差距
总结：虽然有影响，但是整体感知不大，玩家也都能接受。
